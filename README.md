# Game Engine OOP 🎮

This is a small C++ project I made while learning C++ and OOP.

The idea is a simple game engine with different types of entities, such as players and enemies.

In this project, I practiced:

- Classes and objects
- Inheritance
- Abstract classes
- Polymorphism
- Virtual functions
- Function overriding
- Pointers
- Dynamic memory
- Vectors
- Static members
- Destructors

I used a simple game loop to update and display the entities.

I made this project to practice OOP and understand how these concepts can be used in a small game-related project.

I'm still learning C++, so I will probably improve this project and add more things to it later.

Thank you for checking out my project! ❤️
